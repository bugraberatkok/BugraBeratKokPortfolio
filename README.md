# Buğra Berat Kök - Personal Portfolio

A responsive bilingual portfolio for my full-stack, backend, architecture, and AI-integrated work. The design uses graphite surfaces, blue accents, expressive Geist typography, and a portrait-led introduction. Smart Chores Tracker has a featured architecture diagram; supporting projects use a quieter editorial layout.

**[🚀 View Live Portfolio](https://bugra-berat-kok-portfolio.vercel.app/)**

## 💻 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React](https://react.dev/)
- **Styling**: Vanilla CSS with CSS Modules
- **Deployment**: Vercel

## ✨ Features

- **Responsive Design:** Optimized for both desktop and mobile devices.
- **Visual Identity:** Graphite and blue palette, a portrait introduction, clear project hierarchy, visible keyboard focus, and reduced-motion support.
- **Bilingual Content:** English and Turkish content in `locales/en.js` and `locales/tr.js`, with a saved language preference.
- **Single Page Navigation:** Smooth scrolling to About, Projects, Experience, Education, and Contact.
- **Interactive Project Cards:** Smart Chores Tracker, Şifa, WordPress Multisite, Football Analyzer AI, Focus, and FitTrack, with current full-stack and AI-integrated work first.
- **Technical Focus:** Backend development, software architecture, AI agent systems, testing, and delivery; game development remains part of my engineering background.
- **Education & Languages:** Software Engineering (expected January 2027), CEIT double major (completed June 2026), Erasmus, and language proficiency.
- **Experience & Certificates:** A chronological experience layout with native, keyboard-accessible certificate accordions.
